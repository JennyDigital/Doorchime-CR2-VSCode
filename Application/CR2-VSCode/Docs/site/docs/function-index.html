🔍 Quick Lookups

By Task

Play Audio: - Simple blocking: PlaySample() → WaitForSampleEnd() - Non-blocking: PlaySample() → poll GetPlaybackState() - Pause/Resume: PausePlayback() → ResumePlayback() - Stop: StopPlayback() → poll GetPlaybackState()

Configure Filters: - Batch config: GetFilterConfig() → modify → SetFilterConfig() - Single setting: SetLpf16BitLevel(), SetSoftClippingEnable(), etc.

Control Air Effect: - Simple: SetAirEffectPresetDb(preset) (auto-enables when preset > 0) - Advanced: SetAirEffectGainDb() + SetAirEffectEnable() - UI cycling: CycleAirEffectPresetDb()

Adjust Fade Times: - Get/Set pairs: GetFadeInTime() / SetFadeInTime(), etc. - Typical range: 0.0–5.0 seconds

AudioEngine_Init()

PB_StatusTypeDef AudioEngine_Init(
  DAC_SwitchFunc dac_switch,
  ReadVolumeFunc read_volume,
  I2S_InitFunc i2s_init
);

Initialize the audio engine with hardware callbacks. Must be called before any playback.

See: API_REFERENCE.md - Initialization

  uint32_t sample_set_sz,
  uint32_t playback_speed,
  uint8_t sample_depth,

Start playback of an audio sample from memory.

SetFilterConfig()

void SetFilterConfig(const FilterConfig_TypeDef *cfg);

SetAirEffectPresetDb()

void SetAirEffectPresetDb(uint8_t preset_index);

Set air effect using a preset index. Automatically enables air effect if preset > 0, disables if preset == 0.

See: API_REFERENCE.md - Air Effect Control
